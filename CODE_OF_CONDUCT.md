# Code of Conduct

We want this project to be a welcoming place for technical collaboration.

Be respectful, discuss ideas and code rather than attacking people, avoid harassment or discriminatory behavior, and assume good faith while still giving clear technical feedback.

Maintainers may edit, remove, or close contributions or discussions that are abusive, disruptive, unsafe, spammy, or unrelated to the project.

For serious conduct concerns, contact the maintainer privately through the contact method listed on the maintainer's GitHub profile.
