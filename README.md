# HotkeyTrader — Гарын авлага

MetaTrader 5 дээр **гарын товчлуураар** (numpad) арилжаа хийдэг Expert Advisor (EA). Стратеги, автомат шийдвэр байхгүй — энэ бол гараар арилжаалагчийн хурдыг нэмэх хэрэгсэл. Товчлуур дарах бүрд захиалга шууд биржид явна.

- `HotkeyTrader.mq5` — үндсэн EA
- `KeyDetector.mq5` — товчлуурын VK код олох туслах EA (нэг удаа хэрэглээд орхино)

---

## 1. Шаардлага

| Зүйл | Тайлбар |
|---|---|
| Платформ | MetaTrader 5 (**зөвхөн Windows**) |
| Эмхэтгэгч | MetaEditor (MT5-тай хамт ирдэг) |
| DLL | `user32.dll`, `shell32.dll` — MT5-д DLL import зөвшөөрөх ёстой |
| PowerShell | Лотын хэмжээ оруулах цонхонд шаардлагатай |
| NumLock | **ЗААВАЛ ASAAH.** Унтраалттай үед numpad нь сумны код илгээдэг тул товчлуур ажиллахгүй |

---

## 2. Суулгах

1. MT5 → **File → Open Data Folder** → `MQL5\Experts\` фолдер руу `.mq5` файлуудаа хуулна.
2. MetaEditor дээр файлыг нээж **F7** дарж эмхэтгэнэ. Алдаа гарвал Build табд харагдана.
3. MT5 → Navigator дээр баруун товч → **Refresh** → EA-г графикт чирж тавина.

**Чирч тавихад гарах цонхонд:**
- **Common** таб → `Allow Algo Trading` ✔ , `Allow DLL imports` ✔
- **Inputs** таб → доорх параметрүүдийг тохируулна
- Хэрэгслийн мөрний **Algo Trading** товчийг бас асаана (ногоон болсон байх)

> EA нь өөрийг нь тавьсан графикийн симболыг биш, **`InpSymbol` параметрт бичсэн симболыг** арилжаална. Тиймээс аль ч график дээр тавьж болно.

Амжилттай ачаалагдвал Experts табд:
```
[HotkeyTrader] Ready | XAUUSD | Lots=0.01 | Long=0x61 Short=0x62 ... | 1 pip = 10 points
```
Графикийн зүүн дээд буланд одоогийн тохиргоог харуулсан мэдээллийн самбар гарч ирнэ.

---

## 3. Товчлуурууд

| Товчлуур | Үйлдэл | Юу болох |
|---|---|---|
| **Numpad 1** | Long | Зах зээлийн худалдан авах захиалга, одоогийн лотоор |
| **Numpad 2** | Short | Зах зээлийн худалдах захиалга, одоогийн лотоор |
| **Numpad 0** | Break Even | Нээлттэй бүх позицийн SL-г **орсон үнэдээ** зөөнө |
| **Numpad 3** | 20-pip BE | SL-г орсон үнээс **+20 пип ашигтай** цэгт зөөнө |
| **Numpad 5** | Trailing SL | SL-г одоогийн үнээс **10 пипийн зайд** зөөнө (нэг удаагийн, автоматаар дагадаггүй) |
| **Numpad 6** | Лот тохируулах | Лотын хэмжээг гараар бичих цонх нээнэ |

Товчлуур бүр **нэг дарахад нэг л удаа** ажиллана (дарж барьсан ч давтахгүй).

Товчлуурууд нь **глобал** — MT5 идэвхгүй, багасгасан байсан ч ажиллана. Энэ нь давуу тал бөгөөд бас эрсдэл (доорх Анхааруулга хэсгийг үзнэ үү).

---

## 4. Ердийн ажиллагааны урсгал

1. **Numpad 6** дарж лотоо тохируулна (жишээ нь `0.05`).
2. Дохио гарахад **Numpad 1** эсвэл **2** дарж орно.
3. Үнэ ашиг руу явсны дараа **Numpad 0** дарж эрсдэлээ тэглэнэ.
4. Улам явбал **Numpad 3** дарж +20 пип ашгаа түгжинэ.
5. Хүчтэй хөдөлгөөн үед **Numpad 5** дарж SL-г үнэ рүү ойртуулна (шаардлагатай бүрд дахин дарна).
6. Позицийг хаахдаа **MT5-ын Trade табыг гараар** ашиглана — хаах товчлуур EA-д байхгүй.

---

## 5. Оролтын параметрүүд

| Параметр | Өгөгдмөл | Тайлбар |
|---|---|---|
| `InpSymbol` | `XAUUSD` | Бүх үйлдэл явагдах симбол |
| `InpLots` | `0.01` | Эхлэх лотын хэмжээ (Numpad 6-аар дараа нь өөрчилнө) |
| `InpLongKey` | `0x61` | Long товчлуурын VK код (Numpad 1) |
| `InpShortKey` | `0x62` | Short товчлуурын VK код (Numpad 2) |
| `InpBEKey` | `0x60` | Break Even (Numpad 0) |
| `InpBE20Key` | `0x63` | 20 пипийн BE (Numpad 3) |
| `InpTrailKey` | `0x65` | Trailing SL (Numpad 5) |
| `InpLotKey` | `0x66` | Лот оруулах цонх (Numpad 6) |
| `InpPointsPerPip` | `10` | 1 пип хэдэн пойнт вэ (алт: 10 → 1 пип = 0.10) |
| `InpBE20Pips` | `20` | Numpad 3 хэдэн пип ашиг түгжих вэ |
| `InpTrailPips` | `10` | Numpad 5 үнээс хэдэн пипийн зайд SL тавих вэ |
| `InpSlippagePoints` | `20` | Зөвшөөрөх дээд хальтрал (пойнт) |
| `InpMagic` | `20260408` | EA-ын magic дугаар |

Бүх товчлуур параметр учраас **дахин эмхэтгэлгүйгээр** EA-ийн тохиргооны цонхноос өөрчилж болно. Шинэ товчлуурын VK кодыг мэдэхгүй бол `KeyDetector.mq5`-ыг графикт тавиад тухайн товчоо дарж Experts табаас кодыг нь уншина.

### Пип ба пойнт

`1 пип = InpPointsPerPip × SYMBOL_POINT`

2 оронтой алтны ханш дээр: `SYMBOL_POINT = 0.01`, `InpPointsPerPip = 10` → **1 пип = 0.10**.

Өөр симбол руу шилжихдээ энэ утгыг заавал шалгана. Буруу бол SL-ийн зай 10 дахин алдаатай тооцогдоно.

---

## 6. SL зөөх дүрэм (яагаад "skipped" гэж бичигдэв?)

Numpad 0, 3, 5 гурав нь `InpSymbol` дээрх **бүх** нээлттэй позицид үйлчилнэ. Хоёр хамгаалалтын дүрэм:

1. **SL зөвхөн чангардаг** — эрсдэл нэмэгдэх тийш хэзээ ч зөөгдөхгүй.
2. **Брокерын хамгийн бага зай** (`SYMBOL_TRADE_STOPS_LEVEL`) — зорилтот SL нь зах зээлийн үнэд хэт ойрхон бол тухайн позицийг алгасна.

Тиймээс үнэ хангалттай ашиг руу яваагүй байхад Numpad 0 дарвал юу ч болохгүй. Энэ нь алдаа биш — Experts табд ингэж бичигдэнэ:

```
[HotkeyTrader] Break Even: 2 moved, 1 skipped
```

> **Анхаар:** эдгээр үйлдэл позицийг magic дугаараар нь шүүдэггүй, зөвхөн симболоор шүүнэ. Өөрөөр хэлбэл `InpSymbol` дээр гараараа нээсэн эсвэл өөр EA-ийн нээсэн позицийн SL-г бас зөөнө.

---

## 7. Лот оруулах цонх (Numpad 6)

Numpad 6 дарахад PowerShell-ээр жижиг цонх гарч ирнэ (одоогийн лот бичигдсэн байдаг). Шинэ утгаа бичээд **OK**. Цуцлах бол **Cancel** — хуучин лот хэвээр үлдэнэ.

Оруулсан утгыг брокерын алхам/доод/дээд хязгаарт автоматаар нийцүүлж бөөрөнхийлнө (`0.007` → `0.01`).

**Цонх нээлттэй байх хугацаанд бүх товчлуур идэвхгүй болно.** Учир нь та цонхонд бичиж буй тоонууд глобал түвшинд харагдах тул захиалга явуулчих эрсдэлтэй. Иймд **цонхыг нээчихээд мартаж болохгүй** — хаах хүртэл Break Even ч, Trailing ч ажиллахгүй.

Файлын солилцоо MT5-ын `Common Files\Files\` фолдерт явагдана:

| Файл | Чиглэл | Зориулалт |
|---|---|---|
| `ht_lot_input.ps1` | EA → PS | Цонхны скрипт |
| `ht_lot_result.txt` | PS → EA | Бичсэн лот (цуцалсан бол хоосон) |

## 8. ⚠️ Анхааруулга

- **EA үргэлж зэвсэглэсэн байдалтай.** Асаах/унтраах товчлуур байхгүй. Графикт тавьсан тэр мөчөөс Numpad 1 дарвал жинхэнэ захиалга явна.
- **Товчлуурууд глобал.** Өөр програм дээр (Excel, чат, тоглоом) numpad дээр тоо бичихэд захиалга явж мэднэ. Арилжаа хийхгүй үедээ EA-г графикаас авах эсвэл Algo Trading-г унтраахыг зөвлөнө.
- **Орох захиалгад SL/TP тавигддаггүй.** Numpad 1/2 нь хамгаалалтгүй позиц нээдэг. SL-г та өөрөө Numpad 0/3/5-аар эсвэл MT5-аас гараар тавина.
- **Позиц хаах товчлуур байхгүй.** Хаахдаа MT5-ын Trade табыг ашиглана.
- **NumLock унтарвал** бүх товчлуур чимээгүйхэн ажиллахаа болино.
- **Эхлээд демо данс дээр** бүх товчлуураа шалгаад дараа нь бодит данс руу оруулна.

## 9. Алдаа олж засах

| Шинж тэмдэг | Шалтгаан / шийдэл |
|---|---|
| Товчлуур огт ажиллахгүй | NumLock унтарсан; Algo Trading идэвхгүй; DLL import зөвшөөрөөгүй |
| `Ready` мөр Experts табд гарахгүй | EA ачаалагдаагүй — Navigator-оос дахин чирнэ |
| `Buy FAILED retcode=...` | Мөнгө хүрэлцэхгүй, зах зээл хаалттай, эсвэл симбол буруу |
| `Break Even: 0 moved, N skipped` | Үнэ хангалттай ашиг руу яваагүй, эсвэл SL аль хэдийн илүү сайн байрлалд байна |
| `Lot popup: launch failed` | PowerShell хаагдсан/хориотой; антивирус блоклосон |
| Лот цонх гарсан ч товчлуур сэргэхгүй | Цонх нээлттэй хэвээр байна — OK эсвэл Cancel дарна |
| Захиалга явсан ч хариу тодорхойгүй | Numpad 1/2 нь `OrderSendAsync` ашигладаг — үр дүнг Trade/Experts табаас шалгана |

---

## 10. Техникийн товч тайлбар

- `OnTimer()` 10 мс тутам ажиллаж `GetAsyncKeyState`-ээр товчлуурын төлвийг уншина. `OnTick()` зориуд хоосон.
- Орох захиалга — `OrderSendAsync` (хурдан, хариу хүлээхгүй). SL зөөх — `TRADE_ACTION_SLTP`-тэй синхрон `OrderSend`.
- Дүүргэлтийн горимыг (IOC/FOK/Return) симболын `SYMBOL_FILLING_MODE`-оос автоматаар сонгоно.
- Лотыг `NormalizeLot` функц брокерын step/min/max-д нийцүүлнэ.

Илүү дэлгэрэнгүй бүтцийн тайлбарыг `CLAUDE.md`-ээс үзнэ үү.
